# Instructions for Collaborators
## Install Godot
* download Godot Editor from a browser. Be sure to choose the ".NET" version.
* There is no installer for Godot Editor, just place it in a folder of your choice.
## Install .NET SDK
* open powershell
* run the script ./scripts/win_sdk.ps
## Build and Run
* open the Godot Editor 
* open the 'project.godot' in the game folder
* click the play button near the upper right corner of the editor to run the game
* a new window should open and the game should start running
## Making Changes
* We are using GitHub - Recommend you use GitHub Desktop
* Once you have changes, commit them locally
* Then push to remote (aka GitHub Server)
* pull to get the latest changes from the remote (aka GitHub Server)
* (We are not using a complex workflow with branches, pull requests, merges, etc.)
* To begin with, use the NEWASSETS folder as a staging ground to get your assets into our project. 
* Commit the new assets to the NEWASSETS folder, the commit and push.
